# Данил — сайт-визитка

Меню в духе старой консоли: разделы по горизонтали, пункты по вертикали.
Управление: стрелки, колесо мыши, свайпы на телефоне.

## Структура
- `index.html` — разметка и весь контент
- `css/style.css` — оформление и токены цветов в `:root`
- `js/main.js` — логика меню; `js/waves.js` — фон-ленты; `js/boot.js` — ранняя инициализация
- `assets/icons/` — свои SVG-иконки; `assets/avatar.svg` — аватар-монограмма; `assets/fonts/` — шрифты

## Перед публикацией
1. Заменить `ТВОЙ_НИК` на свой Telegram-ник (6 мест в `index.html`).
2. Свою фотографию положить в `assets/avatar.jpg` и поправить `src` в `index.html`.
3. Запускать через статический сервер: `python -m http.server 8000`.
